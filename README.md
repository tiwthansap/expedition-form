## เปิดใช้งาน

ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไรทั้งสิ้น ไม่ต้องมี build step

```bash
git clone https://github.com/<username>/expedition-form.git
cd expedition-form
# เปิดไฟล์ index.html ด้วยเบราว์เซอร์ได้เลย
```

หรือรันผ่านเซิร์ฟเวอร์ในเครื่อง

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

### เผยแพร่ด้วย GitHub Pages

1. ไปที่ **Settings → Pages**
2. Source เลือก **Deploy from a branch**
3. Branch เลือก `main` โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอสักครู่ เว็บจะขึ้นที่ `https://<username>.github.io/expedition-form/`

### กฎการตรวจสอบข้อมูล

- **ชื่อ-นามสกุล** — ต้องมีอย่างน้อย 2 คำ ความยาว ≥ 4 ตัวอักษร รับเฉพาะตัวอักษรไทย/อังกฤษ
- **อีเมล** — ต้องมี `@` และโดเมนที่มีจุดพร้อม TLD ตั้งแต่ 2 ตัวอักษรขึ้นไป
- **เบอร์โทรศัพท์** — ตัวเลข 10 หลัก ขึ้นต้นด้วย 0 (กรองอักขระที่ไม่ใช่ตัวเลขอัตโนมัติ)
- **เลขบัตรประชาชน** — ตัวเลข 13 หลัก และ**คำนวณหลักตรวจสอบ (check digit) แบบ mod 11 จริง**
- **วันเกิด** — ต้องไม่เป็นวันในอนาคต และผู้สมัครต้องมีอายุครบ 18 ปีบริบูรณ์
- **รหัสผ่าน** — ยาวอย่างน้อย 8 ตัว ต้องมีทั้งตัวอักษรและตัวเลข พร้อมมิเตอร์วัดความแข็งแรง 3 ระดับ
- **ยืนยันรหัสผ่าน** — ต้องตรงกับรหัสผ่านทุกตัวอักษร
- **ไฟล์แนบ** — เฉพาะ `.jpg` `.jpeg` `.png` `.pdf` ขนาดไม่เกิน 2 MB
- **กลุ่มตัวเลือก** — บทบาท / ภูมิภาค / ช่องทางติดต่อ ต้องเลือกอย่างน้อยกลุ่มละ 1 รายการ
- **ข้อมูลเพิ่มเติม** — ไม่เกิน 300 ตัวอักษร พร้อมตัวนับแบบเรียลไทม์
- **เงื่อนไข** — ต้องติ๊กยอมรับก่อนส่งใบสมัคร

### ประสบการณ์ผู้ใช้

- ตรวจสอบทันทีเมื่อออกจากช่อง (blur) และแก้สถานะทันทีขณะพิมพ์แก้ไข
- แสดงกรอบเขียว/แดง พร้อมข้อความอธิบายเป็นภาษาไทยรายช่อง
- วงแหวนแสดงความคืบหน้าเป็น % และ checklist 5 หมวดที่อัปเดตตามการกรอก
- อัปโหลดไฟล์ด้วยการลากมาวาง พร้อมแสดงชื่อและขนาดไฟล์
- กดส่งแล้วข้อมูลไม่ครบ จะเลื่อนไปยังช่องแรกที่ผิด พร้อมเอฟเฟกต์สั่นและโฟกัสให้อัตโนมัติ
- ส่งสำเร็จแสดงหน้าสรุปข้อมูล โดยปิดบังเลขบัตรประชาชนบางส่วน
- ปุ่มล้างข้อมูลรีเซ็ตค่า สถานะ ข้อความผิดพลาด สไลเดอร์ ตัวนับ และไฟล์แนบทั้งหมด
- รองรับคีย์บอร์ดเต็มรูปแบบ มี focus ring ชัดเจน และรองรับ `prefers-reduced-motion`
- Responsive ตั้งแต่มือถือถึงจอเดสก์ท็อป

## สำหรับผู้ทดสอบ (Testers)

หน้านี้ **มีข้อผิดพลาดซ่อนอยู่ 2 จุด** ในส่วนของการตรวจสอบข้อมูล ทั้งสองจุดไม่ทำให้หน้าเว็บพัง
และไม่มี error ใน console — ต้องออกแบบเทสเคสแบบ **Equivalence Partitioning** และ
**Boundary Value Analysis** ถึงจะเจอ

- ตารางเทสเคสสำหรับเริ่มทดสอบ → [`docs/TEST-CASES.md`](docs/TEST-CASES.md)
- แบบฟอร์มรายงานข้อผิดพลาด → [`docs/BUG-REPORT-TEMPLATE.md`](docs/BUG-REPORT-TEMPLATE.md)

เจอแล้วเปิด Issue ในรีโพนี้ โดยใช้หัวข้อขึ้นต้นว่า `[BUG]` ได้เลย
