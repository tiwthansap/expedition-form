# ตารางเทสเคส (Test Cases)

ชุดเทสเคสสำหรับทดสอบด้วยมือ เทคนิคที่ใช้: **Equivalence Partitioning (EP)** และ **Boundary Value Analysis (BVA)**
ทุกเคสในตารางนี้มีเคสคู่กันในชุดทดสอบอัตโนมัติ [`tests/validation.test.js`](../tests/validation.test.js) ซึ่งรันผ่านครบ 242/242

> ช่อง "ผลจริง" ให้ผู้ทดสอบกรอกเอง แล้วเทียบกับ "ผลที่คาดหวัง"

---
