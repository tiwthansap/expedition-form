# ตารางเทสเคส (Test Cases)

ใช้เป็นจุดเริ่มต้นในการทดสอบ ผู้ทดสอบสามารถเพิ่มเคสเองได้
เทคนิคที่ใช้: **Equivalence Partitioning (EP)** และ **Boundary Value Analysis (BVA)**

> ช่อง "ผลจริง" ให้ผู้ทดสอบกรอกเอง แล้วเทียบกับ "ผลที่คาดหวัง"

---

## TC-01 ชื่อ-นามสกุล

| # | ข้อมูลนำเข้า | เทคนิค | ผลที่คาดหวัง | ผลจริง |
|---|---|---|---|---|
| 1.1 | (เว้นว่าง) | EP – invalid | ขึ้น "กรุณากรอกชื่อ-นามสกุล" | |
| 1.2 | `สมชาย` | EP – invalid | ขึ้นเตือนให้กรอกทั้งชื่อและนามสกุล | |
| 1.3 | `สม ใจ` | BVA – 5 ตัวอักษร | ผ่าน | |
| 1.4 | `ก ข` | BVA – 3 ตัวอักษร | ไม่ผ่าน (สั้นเกินไป) | |
| 1.5 | `John Smith` | EP – valid | ผ่าน | |
| 1.6 | `สมชาย 123` | EP – invalid | ไม่ผ่าน (มีตัวเลข) | |

## TC-09 การทำงานรวมของฟอร์ม
